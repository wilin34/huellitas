## Huellitas SOS
## Descripcion de la pagina 

Amor, cuidado y bienestar para nuestras mascotas, Huellitas SOS es una app creada para facilitar,ayudar y promover el bienestar animal, es un espacio donde se ofrecen diferentes opciones dependiendo la necesidad de cada paciente segun lo vea necesario su tutor, brindando una vida saludable, feliz y llena de amor para estos pequeñitos de cuatro patas.

## Que ofrecemos 
venta de productos, servicios veterinarios, articulos para el cuidado de mascotas, adopcion responsable, orientacion y adiestramiento para tu mascota

## Para que fue creada Huellitas S.O.S
Huellitas SOS es una clínica veterinaria creada para brindar atención integral a las mascotas, combinando servicios médicos, de grooming, spa y venta de accesorios, con el objetivo de facilitar que los clientes conozcan todos los servicios en un solo lugar, de manera clara y accesible, y también permite agendar citas en línea de forma sencilla.
